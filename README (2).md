# CodeAlpha_EmailExtractor

Python Programming Internship - Task 3 (CodeAlpha): Task Automation.

Extracts all email addresses from a .txt file using regular expressions and saves the unique ones to another file.

## Run
Put your text in `sample_input.txt`, then:
```
python email_extractor.py
```
Output is saved in `extracted_emails.txt`.

## Concepts used
os, re, file handling, sets
