# CodeAlpha_StockPortfolioTracker

Python Programming Internship - Task 2 (CodeAlpha).

A console program that calculates the total value of a stock portfolio using a hardcoded price dictionary.

## Features
- Hardcoded prices for AAPL, TSLA, GOOGL, MSFT, AMZN
- Enter stock name and quantity (repeat stocks add up)
- Input validation (unknown stock, non-numeric, zero/negative quantity)
- Shows total investment and saves it to `portfolio_summary.txt`

## Run
```
python portfolio_tracker.py
```
Type `done` to finish entering stocks.

## Concepts used
dictionary, input/output, arithmetic, functions, file handling
